# Eat It! 视觉规范 v2

> 2026-10-10 · 设计负责人：Raina · 取代 v1。所有界面、小组件、文字卡、动画都按本页做。
> 对照稿：Design 画布《Eat It! Hi-fi Prototype》的 v2 页（7 块画板，07 是品牌与组件板）。旧文件（`index.html`、`docs/DESIGN.md`、`phone-v0.1.html`）的外观一律不参考。

## 1. 一句话
白、黑、灰加一点偏黄的嫩绿，食物用大贴纸，几乎不写字。打开像看自己的冰箱，不像在看一张表。

## 2. 颜色
| 名字 | 值 | 用在哪 |
|---|---|---|
| White | #FFFFFF | 页面、卡片、格子 |
| Mist | #F4F5F1 | 冰箱底、次级背景 |
| Ink | #1F241C | 文字、图标（不用纯黑，不做大面积黑块） |
| Stone | #6F766A | 次要文字 |
| Leaf | #CDEB7B | 主按钮、选中态、App 图标底（偏黄的蔬菜绿） |
| Leaf soft | #E8F5C0 | 选中芯片底、头像底 |
| Leaf deep | #557F12 | 次按钮描边、绿色文字 |
| Sprout | #8DC63F | 语音麦克风按钮、开关、波形 |
| Tomato | #F0533A | "先吃"的点和环 |
| Tomato badge | #CF3A22 | 红色日期标签底（配白字，对比度够） |
| Tomato soft | #FFEDE8 | "Eat first" 区块底 |
| Frost | #E7F0F7 | 冷冻室格子底 |

规则：
- 不出现大面积黑色。黑色只用于文字和细线图标。
- 主按钮：Leaf 填充 + Ink 文字。次按钮：白底 + 1.5px Leaf deep 描边。不要一黑一白的按钮组合。
- 红色只表示"该先吃了"，每屏一处集中出现（Eat first 区块）。

## 3. 字体
- 标题、数字、Logo：**Bricolage Grotesque**，800（粗、有个性，不是常见的 Inter / Roboto / SF）。
- 正文、按钮：**Plus Jakarta Sans**，600。
- 数量一律写数字，并用 Bricolage 加粗显示：写 "3"，不写 "×3"，也不写 "three"。

## 4. 食物：贴纸，不写名字
- 每样食物都是一张"模切贴纸"：主体加一圈白边和柔和阴影。白边可以掩盖抠图的瑕疵，也让整套图风格统一。
- 两种来源：
  1. **图库贴纸**：常见食物（肉、蛋、奶、常见果蔬）用统一风格的扁平插画贴纸，App 自带。
  2. **照片贴纸**：识别不出、或比较偏门的东西（柚子茶、豆腐、亚洲超市的酱料），直接把用户自己拍的照片自动抠成贴纸，加同样的白边。只有这类贴纸下面显示一个小名字。
- 识别彻底失败时，用分类图标兜底（肉、奶、果蔬、其他）。
- 格子里不写名字：用户认得自己买的东西。名字留给读屏和长按查看。
- 贴纸要大：冰箱格子里约 66px，"Eat first" 里约 62px，主屏小组件里约 50px。

## 5. 日期和状态
| 状态 | 表现 |
|---|---|
| 包装上读到的日期 | 红色实心标签：Today / Tomorrow / 2 days |
| 估计的日期 | 白底红色虚线标签 + "~"：~3 days（伦理要求：估计必须看得出是估计） |
| 冷冻 | 浅蓝格子底；最老的一袋加红框和 "4 wk" |
| 共享 | 格子带 Leaf 色描边，分区标题用双人图标 |
| 室友的 | 折叠成一行：锁 + 头像 + 数量，不显示内容 |
不要使用 "2d est" 这类缩写。

## 6. 版式
- 正方形格子网格（冰箱每层 3 格），每层之间一条浅灰"隔板"线，最下面是浅绿色的保鲜抽屉。
- 避免横向长条列表。唯一的列表是扫描结果，做成小票样式：锯齿边、左边分类图标、中间贴纸加名字、右边数字，左右对齐。
- 圆角：大卡 26–32，格子 18–22，按钮胶囊形。触控区不小于 44px。

## 7. 主要交互
- 首页就是冰箱。顶部固定 "Eat first"，下面是 Fridge / Freezer / Pantry 三个标签（Pantry = 常温储物柜，放米、面、酱、面包）。
- 底部中间是一个两半的按钮：左 **Add**（拍照或扫小票），右 **Ate**（语音说吃了什么）。长按后左右拖动是给熟练用户的快捷方式，不作为主要入口。
- 右上角是头像或合租成员，不放语音按钮。
- 分装建议直接给选项：Whole / 2 / 5 / +，默认选中上次的数字。用户改了以后自动记住，以后同一样东西按新的数字建议。
- "Out tonight" 只做成可选的小组件，不放在 App 首页。

## 8. 文案
- 友好、口语、短。每屏正文不超过 12 个英文单词（数字、按钮除外）。
- 不写解释性的副标题、口号和底部说明。例如 "12 items found"、"Photo read on your phone, then deleted"、"Dates read from packs" 都删掉。隐私说明放在设置页和视频旁白里。

## 9. Logo
- 三个方向：A 手机冰箱（推荐，做 App 图标）、B 袋子里的苹果、C 一袋蔬菜。
- 字标："eat it" 用 Bricolage 800 小写，感叹号由一根绿色竖条加一个番茄红圆点组成。
- 不要用被咬了一口的苹果（容易撞 Apple 的标志）。

## 10. 禁止清单
大面积黑块、渐变堆叠、玻璃拟态、紫色、多彩标签、密集文字表格、emoji、AI 生成真人、AI 配音、三星产品图和 Logo、热量、食谱、待办清单、桌面网页版。
