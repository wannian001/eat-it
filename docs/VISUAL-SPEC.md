# Eat It! 视觉规范 v1

> 2026-10-09 · 设计负责人：Raina · 所有界面、小组件、文字卡、动画都按本页做。本页与 Design Brief §7 一致，以本页为准。
> 任何和本页冲突的旧文件（`index.html`、`docs/DESIGN.md`、`phone-v0.1.html`）都不要参考它们的颜色和外观。

## 1. 一句话
白底、黑字、浅绿点缀，食物用真实图片，文字少，留白多。看起来像一个干净的生鲜相册，不像一个记账表格。

## 2. Token
| Token | 值 | 用途 |
|---|---|---|
| `bg` | #FFFFFF | 页面背景 |
| `surface` | #F4F6F1 | 卡片底、输入底 |
| `green-200` | #DDF0C4 | 浅绿强调卡、选中态 |
| `green-500` | #8BC34A（附近，可在 Figma 校准对比度） | 主色、进度环、少量强调 |
| `ink` | #16200F | 主文字、大数字、主按钮底 |
| `muted` | #6B7465 | 次要文字 |
| `use-soon` | 琥珀色（约 #C98A2E） | 快到期 |
| `urgent` | 克制的红（约 #C8443A） | 今天必须处理，少用 |

只用以上颜色。不要自己加新颜色，不要渐变堆叠，不要玻璃拟态，不要紫色，不要多彩标签。

## 3. 字体与形状
- 字体：Plus Jakarta Sans（备选 Manrope / Outfit）。大数字加粗，界面文案为英文。
- 圆角：卡片 20–24px；主按钮胶囊形；录入按钮为圆形。
- 触控区不小于 44px。
- 间距宽松：宁可少放一个元素，也不要挤。

## 4. 食物图片（最重要）
- 用真实食物图片（自己拍的抠图，或商用授权素材），风格统一：白底或透明底、柔和阴影、同一光线方向。
- 不用 emoji，不用卡通食物，不用 AI 生成的人像，不用三星或其他品牌的产品图和 Logo。
- 首页以图为主：像相册一样一格一格排开，每格一件食物，不是表格。

## 5. 文字预算
- 每屏正文不超过 12 个英文单词（标题、按钮、数字除外）。
- 能用图、图标、颜色表达的，就不写字。
- 界面文案用英文；按钮用动词短语（Used it、Use tonight、Eating out）。

## 6. 状态语言
| 状态 | 表现 |
|---|---|
| 包装上的日期 | 实线标签 |
| 估计的日期 | 虚线标签 + "est."（这是伦理要求，不能省） |
| 快到期 | 琥珀色小圆点或描边 |
| 紧急 | 克制的红，每屏最多一处 |
| 冷冻 | 雪花小标 |
| 室友的食物 | 折叠成 "Housemates · N items"，不显示名字和内容 |

## 7. 桌面小组件（所有尺寸都要做）
| 尺寸 | 内容 |
|---|---|
| 小方格 2×2 | 4 个不同食物（例如 4 种水果）的方形图块，每格一种；快过期的那格带琥珀色小点；点一格 = Used it |
| 中号 | 一排 4 个食物图块 + 一行小字（如 "2 use soon"） |
| 大号 | 整个虚拟冰箱，真实食物图摆在隔层上 |
| 锁屏圆形 | 数字 + USE SOON |
| 锁屏矩形 | 一行食物名 + 冻了多久 |
小组件是虚拟冰箱的"出口"，不是新功能。点一下就完成，不需要打开 App。

## 8. 动效（视频里）
- 慢：任何镜头不短于 4 秒。
- 只用淡入、打字机、平移、轻微缩放。不做飞入飞出、3D 旋转、弹跳。
- 文字卡：白底黑字，关键词用浅绿底标出。
- 每个动效都要说明一个功能，否则删掉。

## 9. 禁止清单
渐变堆叠、玻璃拟态、紫色、多彩标签、密集文字表格、emoji、卡通食物、AI 生成真人、AI 配音、三星产品图、热量、食谱、待办清单、桌面网页版。
